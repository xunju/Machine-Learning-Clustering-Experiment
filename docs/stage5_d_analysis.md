# 第五阶段：D 类方法——参数分析、评价与后处理

## 1. 阶段目标

本阶段对 A 类基础空间聚类、B 类运动特征增强和 C 类时序关系建模方法进行统一评价。由于 students003 数据集中没有真实行人组标签，因此本文不使用准确率、召回率和 F1 值等监督指标，而是采用无监督统计指标、连续帧稳定性指标和可视化结果进行综合分析。

## 2. 评价指标

本阶段主要使用以下指标：

| 指标 | 含义 |
|---|---|
| avg_num_clusters | 平均每帧聚类组数 |
| min_num_clusters | 最少聚类组数 |
| max_num_clusters | 最多聚类组数 |
| std_num_clusters | 聚类组数波动 |
| avg_noise_ratio | 平均噪声点比例 |
| avg_runtime_sec | 平均每帧运行时间 |
| ratio_frames_at_least_2_clusters | 至少包含 2 组的帧比例 |
| mean_cluster_count_change | 相邻帧簇数量平均变化 |
| max_cluster_count_change | 相邻帧簇数量最大变化 |

## 3. 分析重点

本阶段重点分析：

1. A 类基础空间聚类方法是否能够满足基本任务要求；
2. B 类运动特征是否改善了聚类结果，或者是否带来过度切分；
3. C 类时序关系方法是否能更好表达持续同行关系；
4. 参数变化如何影响簇数量、噪声比例和稳定性；
5. 哪种方法适合作为 Final 阶段最终视频生成方案。

## 4. A/B/C 方法统一汇总

本阶段将 A 类基础空间聚类、B 类运动特征增强和 C 类时序关系建模方法统一汇总到 outputs/d_analysis/abc_method_summary.csv 中。该表包含方法类别、方法名称、平均簇数、最小簇数、最大簇数、簇数波动、噪声比例、运行时间和每帧至少 2 组比例等指标。

从整体结果看，所有候选方法均覆盖 541 个 time_step，并且最终结果均满足每帧至少 2 组的要求。

## 5. 连续帧稳定性分析

本文进一步计算相邻帧之间的簇数量变化，用 mean_cluster_count_change 衡量连续帧稳定性。该值越小，说明相邻帧之间的组数量变化越平滑。

代表性结果如下：

| 方法 | 平均簇数 | 噪声比例 | 平均簇数量变化 |
|---|---:|---:|---:|
| A-DBSCAN | 4.652 | 0.077 | 0.704 |
| B-window_velocity, eps=0.8, mw=1.0 | 7.652 | 0.317 | 0.791 |
| B-window_velocity, eps=1.0, mw=0.5 | 3.954 | 0.107 | 0.574 |
| B-momentum, eps=1.0, mw=0.5 | 4.011 | 0.103 | 0.493 |
| C-relation_graph, dt=2.5, vt=0.20 | 4.858 | 0.000 | 0.761 |

结果表明，初始 B 类方法由于运动权重较高，容易导致过度切分和较高噪声比例；当 eps 调整为 1.0 且 motion_weight 降低到 0.5 后，window_velocity 和 momentum 方法的平均簇数、噪声比例和连续帧簇数变化均明显改善。

## 6. 参数分析结论

B 类实验说明，运动特征不能简单地与位置特征等权重拼接。若 motion_weight 过高，DBSCAN 在高维特征空间中更容易将行人划分为较多小簇，并产生较多噪声点。适当降低 motion_weight 后，运动特征能够作为空间位置的辅助信息，提高分组的时间稳定性，同时避免明显过度切分。

C 类关系图实验说明，连边阈值对结果影响明显。阈值过严时，图中边过少，会产生大量连通分量；阈值适当放宽后，持续邻近的行人能够形成更合理的组结构。本文选择 dist_threshold=2.5, vel_threshold=0.20 作为关系图方法的代表参数。

## 7. Final 阶段候选方案选择

综合平均簇数、噪声比例、连续帧稳定性、可解释性和视频可视化效果，本文选择 B 类中的 window_velocity 改进方案作为 Final 阶段的主要方法：

- feature_mode = window_velocity
- eps = 1.0
- min_samples = 2
- window_size = 5
- position_weight = 1.0
- motion_weight = 0.5
- 聚类策略 = DBSCAN + KMeans fallback

该方案既保留了短时运动趋势信息，又避免了初始运动特征方案中过度切分和噪声比例过高的问题。相比仅使用 X、Y 的 A 类方法，该方案能够更好体现同行行人的运动一致性；相比 C 类关系图方法，该方案更易控制参数，视频结果也更稳定。因此，本文将其作为最终视频生成策略。
